Before installing tools manually from `.exe` or `.dmg` files, install a **package manager**. It's the difference between "this is on my machine forever" and "I can reproduce this setup in 5 minutes."

Pick your OS — your selection will be remembered across every page on this site.

<Tabs syncKey="os">
  <TabItem label="Windows">

**Recommended: [scoop](https://scoop.sh)**

Open PowerShell (regular user, not admin):

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

Verify:

```powershell
scoop --version
```

**Alternative: [winget](https://learn.microsoft.com/windows/package-manager/)** — preinstalled on Windows 11. Use when scoop doesn't have the package.

**Alternative: [chocolatey](https://chocolatey.org)** — the OG, but most installs require admin.

  </TabItem>
  <TabItem label="macOS">

**Recommended: [Homebrew](https://brew.sh)**

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

After install, Homebrew prints two commands to add itself to your `PATH` — run them. On Apple Silicon it installs to `/opt/homebrew`, on Intel to `/usr/local`.

Verify:

```sh
brew --version
```

  </TabItem>
  <TabItem label="Linux">

Use your distro's built-in package manager:

```sh
# Debian / Ubuntu
sudo apt update && sudo apt install -y build-essential curl git

# Fedora
sudo dnf install -y @development-tools curl git

# Arch
sudo pacman -S --needed base-devel curl git
```

For language-specific tooling, prefer [mise](/env/version-mgrs/mise/) over distro packages — distro versions of Node/Python/Ruby are usually outdated.

  </TabItem>
</Tabs>

## Why we recommend scoop on Windows

- Installs to your user directory (no admin prompts)
- No `PATH` pollution — adds one shim directory
- Easy to uninstall cleanly
- `winget` is fine too but newer / less mature for dev tools
- `choco` is the OG but requires admin for most installs
