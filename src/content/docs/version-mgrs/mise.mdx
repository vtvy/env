[mise](https://mise.jdx.dev) is a version manager for everything — Node, Python, Ruby, Go, Java, Rust, and 100+ more. It's an asdf replacement, written in Rust, with first-class env-var and task-runner features.

## Why mise

- **One tool** — instead of nvm + pyenv + sdkman + rbenv
- **Per-project config** (`mise.toml`) committed to your repo — new devs run `mise install` and they're ready
- **Env vars** built in — replaces `direnv`
- **Tasks** built in — lightweight `make`/`just` alternative
- **Fast** — written in Rust, doesn't slow your shell prompt

## Install

<Tabs syncKey="os">
  <TabItem label="Windows">

```powershell
scoop install mise
```

Then add to your `$PROFILE`:

```powershell
Invoke-Expression (&mise activate pwsh | Out-String)
```

Restart PowerShell.

  </TabItem>
  <TabItem label="macOS">

```sh
brew install mise
```

Add to `~/.zshrc`:

```sh
eval "$(mise activate zsh)"
```

Restart your terminal.

  </TabItem>
  <TabItem label="Linux">

```sh
curl https://mise.run | sh
```

Add to `~/.zshrc` (or `~/.bashrc`):

```sh
eval "$(mise activate zsh)"  # or `mise activate bash`
```

Restart your terminal.

  </TabItem>
</Tabs>

Verify:

```sh
mise --version
```

## What `mise.toml` looks like

```toml
[tools]
node = "20"
python = "3.12"
java = "temurin-21"

[env]
DATABASE_URL = "postgres://localhost/myapp"
LOG_LEVEL = "debug"

[tasks.dev]
run = "npm run dev"

[tasks.test]
run = "npm test"
```

`cd` into the project — `node`, `python`, `java` all snap to the right versions, env vars are loaded.

## Common commands

```sh
mise use node@20         # pin in current project's mise.toml
mise use -g python@3.12  # pin globally for your user
mise install             # install everything mise.toml declares
mise ls                  # list installed versions
mise upgrade             # upgrade mise itself
mise run dev             # run a task from mise.toml
```

## When NOT to use mise

- You're committed to a team standard on another tool (don't fight your team)
- You need a tool mise doesn't support yet (rare — check the registry first)
- Corporate Windows machine with locked-down PowerShell (use scoop/choco for tools and accept manual switching)
