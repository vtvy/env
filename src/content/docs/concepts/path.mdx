`PATH` is an environment variable that holds a list of directories. When you type `python`, the shell walks the list **left to right** and runs the first `python.exe` (Windows) or `python` (Unix) it finds.

## The rules

1. **First match wins.** Order matters.
2. **Directories, not files.** `PATH` doesn't list executables — it lists folders to search in.
3. **The list is just a string.** Separated by `;` on Windows, `:` on Unix.
4. **Children inherit.** Whatever process spawns another passes its `PATH` along (unless explicitly overridden).

## Why "I installed it but the shell can't find it"

The installer put the binary in a folder that isn't on `PATH`, or it added the folder to `PATH` but your current shell session started **before** that change. Open a new terminal — `PATH` is only re-read on shell startup.

## Why "I get the wrong version"

Two installs, both on `PATH`, the earlier one wins. Common offenders:

- **Windows**: `C:\Windows\System32` is near the front of `PATH`. If something dropped a binary there, you'll never escape it.
- **macOS**: Apple ships old Python/Ruby at `/usr/bin`. Homebrew installs to `/opt/homebrew/bin` (Apple Silicon) or `/usr/local/bin` (Intel). Whichever comes first in `PATH` wins.
- **Linux**: Distro packages at `/usr/bin`, manually installed tools at `/usr/local/bin`, user tools at `~/.local/bin`. Order in `PATH` decides.

## Version managers don't replace PATH — they manipulate it

`mise`, `nvm`, `pyenv` all work by **prepending** a "shim" directory to your `PATH`. When you `cd` into a project, the shim figures out which version that project wants and forwards your `python` call to it. That's why they need shell activation (`mise activate`, `nvm.sh`, etc.) — they're modifying your shell's `PATH` on every prompt.

## Diagnosing PATH

<Tabs syncKey="os">
  <TabItem label="Windows">

```powershell
# Print PATH one entry per line
$env:PATH -split ';'

# Which binary will run?
Get-Command python

# All matches in PATH order
Get-Command python -All
```

  </TabItem>
  <TabItem label="macOS">

```sh
# Print PATH one entry per line
echo $PATH | tr ':' '\n'

# Which binary will run?
which python

# All matches in PATH order
which -a python
type -a python
```

  </TabItem>
