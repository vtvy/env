This site uses **synced OS tabs**. Pick your OS in any tab on this page and every other page will default to the same one. Pick once, browse forever.

## Why synced tabs

Setup guides that show all three OSes inline get noisy fast. With synced tabs, you only ever see commands relevant to your machine — without us splitting the site into three near-duplicate copies.
