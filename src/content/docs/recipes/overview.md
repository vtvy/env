Step-by-step setups for the most common stacks. Each recipe assumes you've read [Concepts](/env/concepts/scopes/) and installed a package manager.

Planned recipes:

- **Node + TypeScript** project (`mise` + `pnpm` + VS Code)
- **Python** project (`mise` + `.venv` + `uv` + VS Code or PyCharm)
- **Java + Gradle** project (`mise` + IntelliJ)
- **Full-stack** (Next.js + Postgres + Redis via Docker)
- **Polyglot** project mixing Node, Python, Go in one repo

These pages will land as the site grows. PRs welcome.
